# Mimo — Your Floating Digital Companion
Package: `com.mimo.companion` · Kotlin · Jetpack Compose · Room · Start.io rewarded ads.

* Floating companion (overlay service) with the active look, blinking, drag & tap.
* Mimo Store: 20 looks, ads/points/mixed unlocks, progress per look, "My looks".
* See `docs/STORE_AND_POINTS.md` for configuration and the honest verification status.

Build: push to GitHub → Actions → "Build Mimo" → download `mimo-debug-apk`. Domain tests offline: `tools/run_domain_tests.sh`.
